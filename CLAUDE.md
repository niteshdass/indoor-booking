# Slot Booking

## UI
- All UI follows `.superdesign/design-system.md`. Read it before building or changing any screen.
- Use the tokens in `apps/web/src/styles/tokens.css` (`var(--…)`) for every color, font size, spacing, radius and shadow. No hardcoded values; add a token there (and to the design doc) if one is missing.
- Light and dark mode both have to work; strings must fit Russian as well as English.
