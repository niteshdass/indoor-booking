# Plan 01 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable monorepo with a shared package (money, statuses, permissions), an Express API skeleton backed by MongoDB (replica set, transactions), and a React web skeleton with i18n — the base every later plan builds on.

**Architecture:** pnpm workspace with `apps/api` (Express 5 + Mongoose), `apps/web` (React + Vite) and `packages/shared` (pure TypeScript used by both). API is REST JSON under `/api/v1` with a single error shape. Tests use Vitest; API tests run against `mongodb-memory-server` in replica-set mode so transactions work.

**Tech Stack:** Node 22 LTS, pnpm 9+, TypeScript 5 (strict), Express 5, Mongoose 8, Zod 3, Vitest, Supertest, mongodb-memory-server, React 19, Vite, react-router 7, i18next + react-i18next, @testing-library/react, ESLint (flat config) + Prettier.

**Spec:** `docs/superpowers/specs/2026-10-23-sports-slot-booking-design.md` (roadmap: `docs/superpowers/plans/2026-10-23-roadmap.md`)

## Global Constraints

- TypeScript `strict: true` everywhere; ESM modules (`"type": "module"`).
- All money is integer **minor units** + ISO 4217 code. No floating-point money math anywhere.
- REST JSON API under `/api/v1`; every error response is `{ "error": { "code": string, "message": string, "details"?: unknown } }`.
- MongoDB must run as a replica set (tests: `MongoMemoryReplSet` with 1 member).
- Times stored in UTC (later plans add venue timezone handling).
- i18n from day one: English (`en`) default, Russian (`ru`) second (changed from Bangla on 2026-10-24; task text below shows the original `bn`). No user-visible string hard-coded in components.
- Every owner-scoped collection will carry `ownerId` (enforced from Plan 03; nothing in this plan may contradict it).

## Review Focus

1. Unknown or malformed currency code (`"XYZ"`, `"usd"`, `""`) → throws `InvalidCurrencyError`, never silently treated as 2 decimals.
2. Money input with more decimals than the currency allows (`"10.555"` USD, `"10.5"` JPY) → rejected, not rounded.
3. Malformed JSON request body → `400 invalid_json`, not `500`.
4. Missing `MONGODB_URI` at startup → process fails fast with a message naming the missing variable.
5. Internal error in a handler → `500 internal_error` with no stack trace or error message leaked in the body.

import { currencyExponent, parseMoney, formatMoney, percentOf, assertMinor,
  InvalidCurrencyError, InvalidMoneyError } from '../src/money';

describe('currencyExponent', () => {
  it('knows common exponents', () => {
    expect(currencyExponent('USD')).toBe(2);
    expect(currencyExponent('BDT')).toBe(2);
    expect(currencyExponent('JPY')).toBe(0);
    expect(currencyExponent('KWD')).toBe(3);
  });
  it.each(['XYZ', 'usd', '', 'US'])('rejects %s', (c) => {
    expect(() => currencyExponent(c)).toThrow(InvalidCurrencyError);
  });
});

describe('parseMoney', () => {
  it('parses to minor units without float error', () => {
    expect(parseMoney('12.50', 'USD')).toBe(1250);
    expect(parseMoney('0.29', 'USD')).toBe(29);
    expect(parseMoney('1500', 'JPY')).toBe(1500);
    expect(parseMoney('1.234', 'KWD')).toBe(1234);
    expect(parseMoney('7', 'USD')).toBe(700);
  });
  it.each([['10.555', 'USD'], ['10.5', 'JPY'], ['-1', 'USD'], ['abc', 'USD'], ['', 'USD'], ['1e3', 'USD']])(

describe('percentOf', () => {
  it('rounds half up to whole minor units', () => {
    expect(percentOf(1000, 25)).toBe(250);
    expect(percentOf(999, 50)).toBe(500);
    expect(percentOf(1000, 0)).toBe(0);
    expect(percentOf(1000, 100)).toBe(1000);
  });
  it('rejects percent outside 0..100', () => {
    expect(() => percentOf(1000, -1)).toThrow(InvalidMoneyError);
    expect(() => percentOf(1000, 101)).toThrow(InvalidMoneyError);
  });
});

describe('assertMinor', () => {
  it.each([1.5, -1, NaN, Number.MAX_SAFE_INTEGER + 1])('rejects %s', (v) => {
    expect(() => assertMinor(v)).toThrow(InvalidMoneyError);
  });
});

describe('formatMoney', () => {
  it('formats using currency exponent', () => {
    expect(formatMoney(1250, 'USD', 'en-US')).toBe('$12.50');
    expect(formatMoney(1500, 'JPY', 'en-US')).toBe('¥1,500');
  });
});
